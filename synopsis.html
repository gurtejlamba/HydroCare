1. Project Title & Problem Statement

Title: HydroCare – Smart Daily Hydration Tracker

Most people do not drink enough water daily, and the amount required changes with the weather — a hot day demands significantly more intake than a cool one. Existing apps set a fixed goal for everyone regardless of environmental conditions. HydroCare solves this by automatically adjusting the daily water goal based on real outdoor temperature, while layering in streak tracking, smart reminders, and a 7-day history chart to turn passive logging into an active daily habit.

2. Objectives & Proposed Solution

Objectives:

  1. Make daily water intake tracking frictionless — one tap to log, no setup required.
  2. Automatically adjust the hydration goal based on real-world temperature at the user’s location.
  3. Build accountability through streak tracking and visual 7-day progress.
  4. Remind users intelligently without being intrusive (quiet hours, stop when goal is met).

Solution: On launch the app fetches device GPS coordinates and queries Open-Meteo (a free, key-free weather API) for the current temperature. The goal is set as follows:

TemperatureDaily GoalRationale
Below 25 °C2,000 mlBaseline daily requirement
25 °C – 32 °C2,500 mlModerate heat increases sweat loss
Above 32 °C3,000 mlHigh heat — significant fluid depletion

If location or internet is unavailable the app defaults silently to 2,000 ml and continues to function fully offline.

3. App Features

3.1 Weather-Based Dynamic Goal

Uses Android LocationManager to obtain GPS/network coordinates, then calls api.open-meteo.com/v1/forecast?latitude=<lat>&longitude=<lon>&current=temperature_2m on a background thread. The returned temperature sets one of three daily goals. The goal is stored in SharedPreferences under a date key (goal_YYYY-MM-DD) so the 7-day chart can display accurate goal lines for past days.

3.2 One-Tap Logging & Live Progress

Three Material buttons (+250 ml, +500 ml, +750 ml) log a drink in under two seconds. A horizontal progress bar, large intake counter, and contextual motivational message update immediately. Entries are stored with a timestamp in a newline-separated log. The app resets automatically at midnight — no user action needed.

3.3 Streak Counter NEW

Displayed in bold orange below the app title. Each midnight reset checks whether the previous day’s saved intake met or exceeded that day’s goal. If yes, the streak increments; if not, it resets to zero. Past intake is persisted under intake_YYYY-MM-DD keys so the comparison survives app restarts.

3.4 Smart Reminders NEW

A toggle button lets users enable periodic reminders (30 min / 1 hr / 2 hr interval chosen via dialog). Reminders are implemented with AlarmManager.setInexactRepeating (battery-efficient) and a BroadcastReceiver. On Android 13+ the POST_NOTIFICATIONS runtime permission is requested. Smart suppression rules prevent annoying notifications: reminders are silently skipped during quiet hours (10 PM – 7 AM) and when the daily goal is already met. A BootReceiver reschedules alarms after device reboot. The notification body shows remaining ml to goal.

3.5 7-Day History Chart NEW

HydroChartView is a custom View drawn entirely on Canvas using the Android Paint API — no third-party charting library. Seven bars represent the last 7 days. A dark-blue bar indicates the goal was met; light-blue indicates it was not. An orange dashed line marks each day’s goal (which can differ across days due to weather). Today’s label is bold blue. The chart updates live with every drink logged.

6. Usability

Target Users: General public, people in hot climates, athletes, health-conscious individuals, outdoor workers, and anyone who wants a low-friction hydration habit.

Practical Use: The user opens the app once in the morning. Temperature-based goal is set automatically. Reminders fire every hour until the goal is met. Throughout the day the user taps one button per drink. The streak counter creates a daily return incentive. The 7-day chart provides a quick weekly overview without navigating away.

Benefits:

  • Context-aware goal removes guesswork on hot days
  • Reminders stop once goal is met — not intrusive
  • Streak system converts a passive tracker into a habit loop
  • 7-day chart provides accountability at a glance
  • No account, no subscription, works fully offline
  • Entire logging interaction takes under 3 seconds

9. Conclusion

HydroCare demonstrates that a focused, well-engineered Android application can deliver genuine health value without external libraries, paid APIs, user accounts, or cloud storage. By combining weather-aware goals, streak-based motivation, smart non-intrusive reminders, and a live 7-day history chart, the app transforms a simple water log into a complete hydration management system. All data stays on-device, battery impact is minimal, and the app functions fully offline — making it accessible to the widest possible audience.
